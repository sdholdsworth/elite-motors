# Stylish Vehicle Motor Sales App

Welcome to the Stylish Vehicle Motor Sales App! This application streamlines the process of browsing, selecting, and purchasing vehicles with a modern and user-friendly interface.

## Features

- Browse a wide range of vehicles
- Advanced search and filter options
- Detailed vehicle specifications
- Responsive design for all devices
- Save favourite vehicles to garage
- User friendly, accessible & easy to use interface

## Project Goals

- A medium-to-large, full-stack vehicle sales website, utilising the MERN stack - No TypeScript (version 2 of this project will be a TypeScript based version).

- This project will entail all the main concepts you would expect of a professional, customer facing, fully-fledged, e-commerce vehicle sales website:

  * Semantic component architecture 
  * WCAG accessibility compliance 
  * Responsive design (mobile-first) 
  * Cross-browser compatibility 
  * Authentication
  * Authorization
  * API design
  * 3rd party API integrations 
  * Data configuration
  * Routing
  * Theme (light/dark)
